TRADING AI — REAL DEMO iPhone

COSA FA
- Interfaccia ottimizzata per iPhone/PWA.
- Feed prezzi REAL-TIME tramite WebSocket pubblico Binance.
- Modalità DEMO: ordini solo simulati, nessun denaro reale.
- Modalità LIVE READONLY: visualizza il mercato ma non invia ordini.
- 10 agenti: Trend, Momentum, RSI, MACD, Breakout, Volatility, Volume,
  Mean Reversion, Structure e RiskGuardian.
- Un solo trade aperto alla volta.
- Valuta i segnali a intervalli realistici e usa stop/target.
- Win-rate calcolato SOLO sui trade demo realmente chiusi.

IMPORTANTE
Il win-rate del video non è una proprietà che si possa garantire o copiare
identicamente: il mercato reale cambia. Questo progetto evita di inventare
profitti e misura i risultati della simulazione.

USO
1. Carica tutti i file in un repository GitHub.
2. Attiva GitHub Pages dalla cartella root.
3. Apri il link Pages su Safari iPhone.
4. Usa Condividi > Aggiungi alla schermata Home.

DATI
La demo usa il prezzo live del simbolo selezionato tramite Binance WebSocket.
Per azioni, forex o indici serve un feed dati specifico con licenza/API.
